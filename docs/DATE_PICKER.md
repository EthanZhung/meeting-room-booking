# 日期選擇器

預約頁以 Vanilla JS 增強原生 `#date`，顯示日期格式為 `YYYY/MM/DD`。原生欄位仍保留 `type="date"`、`name`、`min`、`required`、`validity` 與 `YYYY-MM-DD` 值，既有預約 API 不變。

## 元件介面

`new ReservationDatePicker(input, options)` 建立元件；`sync()` 同步外部修改的日期值及可選狀態。

- `mode`：預設 `single`。`range` 為可選區間模式，預約表單不啟用。
- `getUnavailableReason(dateISO)`：回傳禁用原因；可選日期回傳空字串。預約頁僅在資料載入成功後，使用既有時段重疊與午休計算，判斷當日是否完全訂滿。

區間模式透過原生欄位發出冒泡的 `date-range-change` 事件，`event.detail` 為 `{ start, end, nights }`。尚未選定結束日時 `end` 為 `null`、`nights` 為 `0`。區間內包含禁用日期時不接受該終點。

沒有載入元件時，原生日期欄位仍可使用。側欄行事曆選取、日期變更與表單重設仍透過原有流程更新。

## 動畫與操作

珊瑚紅主色 `#E11D48`，淺底 `#FFF1F2`，邊框 `#FDA4AF`，深色文字 `#9F1239`。彈窗依點擊位置設定縮放原點；月份切換使用方向滑動；月份總覽使用語意縮放；日期選取使用彈跳，無效日期提供震動與原因提示。

支援方向鍵、Home／End、PageUp／PageDown、Enter、Escape 與 Tab。系統設定減少動態效果時改為 130ms 透明度過渡。高度自適應是需求明定的 230ms 尺寸動畫，會涉及版面計算；其餘位移及縮放僅使用 transform／opacity，無法據此保證所有裝置達到 60fps。
