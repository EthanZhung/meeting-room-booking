# 玻璃介面與填寫流程

## 介面

- 三頁共用淺色玻璃主題、主題色與系統字型。頁面頂部直接呈現主要內容。
- 導覽膠囊滑塊隨滑鼠與鍵盤焦點移動，離開後回到目前頁面。
- 預約欄位依日期時段、會議資訊、預約人資訊排列。會議室設備及使用時間可展開查看；桌面行事曆先於摘要。
- 必填與格式錯誤提供欄位提示及可點擊摘要；連結可聚焦自訂下拉按鈕，摘要隨欄位修正更新。
- 查詢頁採較窄內容區，寬螢幕頁首與卡片對齊。電子郵件欄位為無外框的藍灰底色，保留浮動標籤與聚焦底線。
- 三頁 favicon 與 Apple touch icon 使用 `public/site-icon.png`。

## 互動與資料來源

原生 select 是選項、值、表單驗證及 disabled 狀態的來源。`dropdown.js` 漸進增強時間、時長、年份及月份選單；沒有 JavaScript 時保留原生控制項。元件保留 input/change 事件，日期程式設值以 selectsync 同步，重設後也同步顯示。

下拉面板使用 Popover 頂層，避免被玻璃卡片裁切；不支援時退回固定定位面板。支援方向鍵、Home、End、Enter、Space、Escape、Tab、文字搜尋及外部點擊收合。面板約 380ms 回彈展開，選項各間隔 50ms 淡入。

紙飛機按鈕由既有操作發出的 plane:start、plane:success、plane:error 驅動。必須通過驗證才開始飛行，實際成功才顯示「已送出」，約一秒後文字與圖示返回。動畫不另行發出預約請求。

動態採原生 CSS 與 JavaScript，不新增框架或 GSAP 相依套件。提供減少動態、減少透明度、強制色彩及背景模糊不支援時的替代規則。

## 驗證

已在本機瀏覽器驗證三頁導覽、桌面與 320px 手機版面、選單鍵盤操作、日期與年月同步、時間計算、表單重設及錯誤摘要連結。查詢使用無對應預約的測試地址，確認送出動畫、成功提示及復原。寬螢幕下查詢頁首與卡片寬度皆為 802px。

預約成功、失敗與再次操作時的動畫另以不載入預約 API 的隔離頁驗證。未新增或取消真實預約，未以實體觸控裝置或切換作業系統輔助模式驗證。背景模糊與輔助模式替代規則經程式碼檢視。

JavaScript 語法、HTML ID／label／ARIA 關聯與 git diff 空白檢查通過。
